Help & documentation

How to use the DengueWatch AI prototype.

Using the dashboard

Select a city and ward to explore the example ward-level indicators. Choose a 2, 3 or 4 week period to update the prediction display.

Understanding risk levels

Low, Medium, High and Critical are displayed as risk tiers. The score bands on the Risk Prediction page are illustrative placeholders and must be replaced with thresholds validated by your project team.

About the data shown

This frontend currently uses illustrative sample values based on the supplied dashboard design. It is not connected to Supabase or a prediction model. Replace the sample objects in js/app.js with API responses when the backend is ready.

Important: This tool is a public-health decision-support prototype, not a clinical diagnosis or a substitute for official surveillance guidance.
